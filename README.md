GestureFX – AI Hand Gesture Visual Effects

GestureFX is a Python-based computer vision project that detects hand gestures using a webcam and triggers interactive superhero-style visual effects.

Features
🖐️ Hand gesture detection
⚡ Real-time visual effects
🛡️ Energy shield effect
⚡ Energy beam effect
💥 Energy blast effect
🌀 Portal effect
Technologies
Python
OpenCV
MediaPipe
NumPy
How it works

Webcam → Hand Detection → Gesture Recognition → Visual Effect
